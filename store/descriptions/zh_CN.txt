FormDitto 是一款表单自动填写工具，适合每天都要提交同类网页表单的人：服务申请、订单、工单、注册等。只需把表单保存一次为模板，按需保存多个变体（“B 型泵”“C 型泵”…），即可一键填写整张表单。

使用方法
1. 打开表单，点击 FormDitto 图标。页面旁边会打开侧边栏。
2. 点击“新建模板”，点击需要的字段（或“添加所有可见字段”），然后输入它们的值。
3. 这些值会成为第一个变体。可以在侧边栏中添加更多变体，并复制和编辑它们。
4. 下次使用时：选择一个变体，检查预览，点击“填写”。已更改的字段会高亮显示，点击“撤销”即可恢复之前的值。

可填写的内容
• 文本、电子邮件、电话和数字字段，多行文本框
• 下拉列表、复选框、单选按钮、日期
• React 和 Vue 表单（受控输入框会收到真实的 input 和 change 事件）
• 稍后加载的列表和字段：FormDitto 会在超时时间内等待它们
• 同一网站的 iframe 和 Web 组件（开放的 shadow DOM）

注重隐私，谨慎可靠
• 模板只保存在此设备的浏览器中。没有账号、没有服务器、没有分析，也没有任何网络请求。
• 每次只请求访问一个网站，并且只有在您允许时才会请求。
• 每个模板都绑定到录制它的网站。在其他任何网站上（例如仿冒您门户网站的副本），FormDitto 会在填写前显示明确的警告。
• 绝不录制或填写密码、支付卡字段和隐藏字段。
• 绝不提交表单。由您自己检查并点击“提交”。

导入和导出
以 JSON 文件的形式将模板转移到另一台电脑，或与同事共享。导入的文件会经过严格检查。

免费
模板、变体、预览和撤销功能全部免费。无需订阅。

支持 14 种语言。适用于 Google Chrome 和 Microsoft Edge 116 或更高版本。
