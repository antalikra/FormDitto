FormDitto は、サービス依頼、注文、問い合わせ、登録など、同じ種類の Web フォームを毎日送信する方のためのフォーム自動入力ツールです。フォームを一度テンプレートとして保存し、ケースごとにバリエーション（「ポンプ タイプ B」「ポンプ タイプ C」…）を用意すれば、フォーム全体をワンクリックで入力できます。

使い方
1. フォームを開き、FormDitto アイコンをクリックします。ページの横にサイドパネルが開きます。
2. 「新しいテンプレート」をクリックし、必要な項目をクリック（または「表示中の項目をすべて追加」）して値を入力します。
3. 入力した値が最初のバリエーションになります。パネルでバリエーションを追加、複製、編集できます。
4. 次回からは、バリエーションを選んでプレビューを確認し、「入力」をクリックするだけ。変更された項目はハイライトされ、「元に戻す」で以前の値に戻せます。

入力できるもの
• テキスト、メール、電話番号、数値の欄、複数行のテキスト欄
• ドロップダウンリスト、チェックボックス、ラジオボタン、日付
• React と Vue のフォーム（制御された入力欄に本物の input / change イベントを送ります）
• 後から読み込まれるリストや項目：タイムアウト付きで待機します
• 同じサイトの iframe と Web コンポーネント（オープンな Shadow DOM）

プライバシーと安全性
• テンプレートはこのデバイスのブラウザ内にだけ保存されます。アカウント、サーバー、分析、ネットワーク通信は一切ありません。
• アクセスはサイトごとに、許可したときだけ要求されます。
• 各テンプレートは記録したサイトに紐づきます。他のサイト（ポータルをまねた偽サイトなど）では、入力前にはっきりと警告を表示します。
• パスワード、支払いカードの欄、非表示の項目は記録も入力もしません。
• フォームを送信することはありません。内容を確認して送信するのはあなたです。

インポートとエクスポート
テンプレートを JSON ファイルとして別のパソコンに移したり、同僚と共有したりできます。インポートするファイルは厳密にチェックされます。

無料
テンプレート、バリエーション、プレビュー、元に戻す機能はすべて無料です。サブスクリプションはありません。

14 言語に対応。Google Chrome と Microsoft Edge 116 以降で動作します。
