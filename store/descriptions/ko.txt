FormDitto는 서비스 요청, 주문, 문의, 등록처럼 같은 종류의 웹 양식을 매일 제출하는 분을 위한 양식 자동 입력 도구입니다. 양식을 한 번 템플릿으로 저장하고 경우별로 변형('펌프 유형 B', '펌프 유형 C'…)을 만들어 두면 양식 전체를 클릭 한 번으로 입력할 수 있습니다.

사용 방법
1. 양식을 열고 FormDitto 아이콘을 클릭합니다. 페이지 옆에 사이드 패널이 열립니다.
2. '새 템플릿'을 클릭하고 필요한 필드를 클릭(또는 '보이는 필드 모두 추가')한 다음 값을 입력합니다.
3. 입력한 값이 첫 번째 변형이 됩니다. 패널에서 변형을 추가하고 복제하고 편집할 수 있습니다.
4. 다음부터는 변형을 고르고 미리 보기를 확인한 뒤 '입력'을 클릭하면 됩니다. 바뀐 필드는 강조 표시되고 '실행 취소'로 이전 값을 복원할 수 있습니다.

입력할 수 있는 항목
• 텍스트, 이메일, 전화번호, 숫자 필드와 여러 줄 텍스트 영역
• 드롭다운 목록, 체크박스, 라디오 버튼, 날짜
• React와 Vue 양식(제어 입력란에 실제 input·change 이벤트를 보냄)
• 나중에 로드되는 목록과 필드: 제한 시간 내에서 기다립니다
• 같은 사이트의 iframe과 웹 컴포넌트(열린 shadow DOM)

개인정보 보호와 안전
• 템플릿은 이 기기의 브라우저에만 저장됩니다. 계정, 서버, 분석, 네트워크 요청이 없습니다.
• 접근 권한은 사이트별로, 허용할 때만 요청합니다.
• 각 템플릿은 기록한 사이트에 연결됩니다. 다른 사이트(예: 포털을 흉내 낸 가짜 사본)에서는 입력하기 전에 분명한 경고를 표시합니다.
• 비밀번호, 결제 카드 필드, 숨겨진 필드는 절대 기록하거나 입력하지 않습니다.
• 양식을 제출하지 않습니다. 확인하고 제출하는 것은 사용자입니다.

가져오기와 내보내기
템플릿을 JSON 파일로 다른 컴퓨터에 옮기거나 동료와 공유할 수 있습니다. 가져오는 파일은 엄격하게 검사합니다.

무료
템플릿, 변형, 미리 보기, 실행 취소 기능은 모두 무료입니다. 구독이 없습니다.

14개 언어 지원. Google Chrome 및 Microsoft Edge 116 이상에서 작동합니다.
